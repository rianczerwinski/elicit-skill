# elicit

Gather accurate requirements, preferences, and tacit knowledge through concrete alternatives and drafts people can react to.

## Use

> Help me clarify what I need. Show me a concrete strawman before asking abstract questions.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `elicit/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
